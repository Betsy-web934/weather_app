# Weather App

A command line weather app built with Python. Enter a city name and it shows the current temperature, conditions, humidity and wind speed using the OpenWeatherMap API.

## Setup

1. Install the dependencies:
```
   py -3.14 -m pip install -r requirements.txt
```
2. Get a free API key from openweathermap.org.
3. Create a `.env` file in the project folder containing:
```
   API_KEY=your_key_here
```

## Run

```
py -3.14 main.py
```
